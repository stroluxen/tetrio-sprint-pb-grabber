a small project to collect TETR.IO players clearing 40 lines as fast as possible.

Enter all of the TETR.IO usernames in the "input.txt" file in the format below, case insensitive, and run main.py to get the output:

username1
username2
username3
username4

Copy the output of the one player and press CTRL + SHIFT + V in your sheet, starting at the Name column. Stacking is set to 6-3 by default because most players uses that stacking method.
